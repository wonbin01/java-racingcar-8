# java-racingcar-precourse

## 자동차 경주

해당 프로젝트는 사용자로부터 자동차의 이름과 시행 횟수를 입력받는다. 각 시행마다 각각의 자동차는 랜덤 변수를 생성해 특정 숫자 이상이면 전진, 아니면 멈춰있도록 하고 이를 화면으로 표시한다. 사용자가 입력한 시행
횟수가 종료된 이후 우승한 자동차의 이름을 출력하는 프로젝트이다.

---

## 프로젝트 흐름

1. 입력 받기
    1. 경주할 자동차 이름을 쉼표(,)를 기준으로 입력받는다.
        1. 특수 문자나 올바르지 않은 구분자가 사용된 경우 오류를 발생시킨다.
        2. 중복된 이름이나, 비어있는 경우에도 오류를 발생시킨다. (단, 공백은 제거하고 진행한다.)
        3. 5자가 초과하는 경우에도 오류를 발생시킨다.
        4. 터미널 환경이나 시스템 차이로 인코딩 오류가 발생할 수 있으므로, 입력은 영어+숫자 조합으로 제한하며 이를 어길 시 오류를 발생시킨다.
        5. 한 명만 입력돼도 1등이므로 정상 처리
    2. 사용자가 몇 번의 입력을 할지 입력받는다.
        1. 음수가 입력된 경우 오류를 발생시킨다.
        2. 0이 입력된 경우, 오류를 발생시킨다.
        3. 숫자가 입력되지 않고 다른 문자가 입력된 경우 오류를 발생시킨다.
        4. 최대 허용 범위: long의 최대값까지 허용 (약 9경)
2. 게임 실행
    1. 전진/정지 결정
        1. 각 시행마다 각 자동차에 대해 랜덤 변수를 생성한다. (0부터 9사이의 정수)
        2. 생성된 랜덤 변수가 4이상인 경우 해당 자동차는 1만큼 전진한다.
        3. 매 시행 후, 진행 상황을 출력한다.
3. 결과 출력
    1. 모든 시행이 완료된 후, 가장 멀리 전진한 자동차의 이름을 출력한다.
    2. 공동 우승자가 존재하는 경우, 쉼표(,)로 구분하여 모두 출력한다.

---

## 입력/출력 예시

| 이름 입력            | 시도 횟수 입력 | 결과                  |
|:-----------------|:--------:|:--------------------|
| `pobi,woni`      |   `3`    | pobi                |
| `pobi,,woni`     |   `3`    | 빈 이름은 사용할 수 없습니다.   |
| `pobi,pobi,woni` |   `1`    | 중복된 이름이 존재합니다.      |
| `Lamborghini`    |   `2`    | 이름이 5자를 초과합니다.      |
| `pobi,woni`      |   `0`    | 시행 횟수는 1 이상이어야 합니다. |
| `pobi,woni`      |   `-1`   | 시행 횟수는 1 이상이어야 합니다. |
| `pobi,woni`      |   `한번`   | 숫자만 입력 가능합니다.       |
| `포비,우니`          |   `4`    | 이름은 영어와 숫자만 가능합니다.  |

## 테스트

본 프로젝트는 입력 검증 로직(InputException)과 레이싱 로직(Racing)에 대한
단위 테스트를 JUnit 5와 AssertJ를 사용하여 작성했다.

| 구분                             | 테스트 항목              | 기대 동작 / 예외 메시지            |
|--------------------------------|---------------------|---------------------------|
| **자동차 이름 입력 (InputException)** | 이름이 비어있을 때          | `입력이 비어있습니다.`             |
|                                | 중간에 빈 이름이 존재할 때     | `빈 이름은 사용할 수 없습니다.`       |
|                                | 중복된 이름이 존재할 때       | `중복된 이름이 존재합니다.`          |
|                                | 이름이 5자를 초과할 때       | `이름은 5자를 초과할 수 없습니다.`     |
|                                | 영어/숫자 이외 문자가 포함될 때  | `이름은 영어와 숫자로만 구성되어야합니다.`  |
|                                | 정상 입력 시             | 예외 없음                     |
| **시도 횟수 입력 (InputException)**  | 입력이 비었을 때           | `시도 횟수를 입력해야 합니다.`        |
|                                | 1 미만의 수가 입력된 경우     | `시도 횟수는 1 이상이어야 합니다.`     |
|                                | `Long` 범위를 초과한 수 입력 | `최대 시도 횟수를 넘겼습니다.`        |
|                                | 숫자가 아닌 문자가 입력된 경우   | `정수를 입력해야 합니다.`           |
|                                | 정상 입력 시             | 예외 없음                     |
| **레이싱 로직 (Racing)**            | 주행 거리만큼 하이픈(`-`) 출력 | 거리=2 → `"--"`             |
|                                | 최대 거리 자동차 우승자 계산    | `최종 우승자 : pobi`           |
|                                | 최대 거리 값 검증          | `getMaxDistance()` → `2L` |

### 대표 테스트 코드 예시

```java

@Test
void 숫자입력시_LONG_이상의_수가_입력된_경우_오류발생() {
    InputException inputException = new InputException();
    assertThatThrownBy(() ->
            inputException.validateNumbers("9223372036854775808"))
            .isInstanceOf(IllegalArgumentException.class)
            .hasMessage("최대 시도 횟수를 넘겼습니다.");
}

@Test
void 최대_거리_운전자가_우승자로_출력() {
    Car pobi = new Car("pobi");
    Car woni = new Car("woni");
    pobi.incrementDistance();
    pobi.incrementDistance();
    Racing racing = new Racing(List.of(pobi, woni), 1);

    String result = racing.printWinner();
    assertThat(result).isEqualTo("최종 우승자 : pobi");
}
```
